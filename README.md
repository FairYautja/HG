# Predator: Hunting Grounds Guide

Community made guide to Predator: Hunting Grounds game.

## TLDR

  1. Clone this repository
  2. Change into Docusaurus `cd hguide/docusaurus`
  3. Install needed libraries `yarn`
  4. Start local site `yarn start`

  5. Unpack PAK files from `Program Files/Epic Games/PredatorHuntingGrounds/SpaceFish/Content/Paks/`
     using either UNREALPAK.EXE (which comes with Unreal Engine) or FModel. Following folders are used:
      - SpaceFish/Content/Character
      - SpaceFish/Content/DLC_Release
      - SpaceFish/Content/UI/Icons
      - SpaceFish/Content/Weapon

  6. Run `python -mscripts SpaceFish docusaurus`
