# Predator Specializations

Passive abilities that provide buffs to enhance specific playstyles.
Each class has access to a different set of specializations.


## Stats

    Spec_Disciplined: { good_negative: true },
    Spec_Savage: { callback: (value) => value + 1 },

}

}
