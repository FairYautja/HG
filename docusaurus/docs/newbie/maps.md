# Maps

Each map has fixed spawn locations. The Fireteam's insertion point is
typically on the opposite side of the map from the Predator's spawn. On some
maps the infil location is predictable enough that the Predator can move there
early to intercept, and conversely, an experienced Fireteam can often tell
which direction the Predator is coming from.

Boars spawn at fixed spots — usually near enemy bases — and are triggered by
the Fireteam entering the area. Ammo crates and medkits are also mostly fixed,
with a few that rotate between a set of predetermined locations. Learning these
spots is worthwhile for both sides, as knowing where to find healing or ammo
in a pinch can decide a match.
