## Class Attributes

Every Fireteam class has passive bonuses that are always active. Multipliers are shown as a
percentage change of the affected value. Green means the change helps the player, e.g.
*Sprint damage resist* `-20%` means 20% less damage taken while sprinting.

export const attributeRows = data.characters.fireteam.flatMap((c) =>
    (c.class_attributes || []).map((a) => ({ ...a, id: `${c.id}:${a.id}`, class_name: c.name, class_icon: c.icon, attribute: a.name }))
);

export const ATTRIBUTE_LOWER_IS_BETTER = new Set([
    // Lower value benefits the player (damage taken, spread, time to get muddy, body
    // temperature). Attributes in neither set are left uncolored.
    'FT_ClassAttribute_HipFireAccuracy',
    'FT_ClassAttribute_MuddyDuration',
    'FT_ClassAttribute_SprintingDamageReduction',
    'FT_ClassAttribute_ProximityResitance',
    'FT_ClassAttribute_ExplosionResistance',
    'FT_ClassAttribute_PredResistence',
    'FT_ClassAttribute_MuddyDamageResistance',
    'FT_ClassAttribute_ReducedThermalTemp',
    'FT_ClassAttribute_IncreasedThermalTemp_TESTING',
]);
export const ATTRIBUTE_HIGHER_IS_BETTER = new Set([
    'FT_ClassAttribute_LongerSpots',
    'FT_ClassAttribute_PostSprintDamageBoost',
    'FT_ClassAttribute_BulletWeaponDamage',
    'FT_ClassAttribute_TeamAmmo',
    'FT_ClassAttribute_ExtraAmmo',
    'FT_ClassAttribute_LongShot',
    'FT_ClassAttribute_HipFireDamage',
    'FT_ClassAttribute_SecondaryWeaponDamage',
]);
export const ATTRIBUTE_UNITS = {
    'FT_ClassAttribute_ReducedThermalTemp': ' °C',
    'FT_ClassAttribute_IncreasedThermalTemp_TESTING': ' °C',
};

export function fmtAttribute(row) {
    const v = row.modifier;
    const attributeId = row.id.split(':')[1];
    const title = `${row.source}: ${v} (${row.usage})`;
    if (typeof v !== 'number') return <span title={title}>{String(v)}</span>;
    const isAdd = row.usage === 'IntAdd' || row.usage === 'FloatAdd';
    const neutral = isAdd ? 0 : 1;
    const style = { fontWeight: 'bold' };
    if (v !== neutral && ATTRIBUTE_LOWER_IS_BETTER.has(attributeId)) {
        style.color = v < neutral ? '#218409' : '#f0001f';
    } else if (v !== neutral && ATTRIBUTE_HIGHER_IS_BETTER.has(attributeId)) {
        style.color = v > neutral ? '#218409' : '#f0001f';
    }
    if (isAdd) {
        return <span style={style} title={title}>{v > 0 ? '+' : ''}{v}{ATTRIBUTE_UNITS[attributeId] ?? ''}</span>;
    }
    const pct = Math.round((v - 1) * 100);
    return <span style={style} title={title}>{pct > 0 ? '+' : ''}{pct}%</span>;
}

## Common Stats

These values are the same for every Fireteam class. *Armor* is a multiplier applied to incoming
damage of the given damage type, *Self armor* applies to damage from your own explosives.

export const ft = data.characters.fireteam;
export const downedHealth = commonValue(ft, 'downed_health');
export const downedBleed = commonValue(ft, 'downed_bleed');
export const commonRows = [

## Body Parts

Fireteam classes have no body part modifiers: a hit deals the same damage to the head, body, arms
and legs. Only the attacking weapon can add a headshot bonus, see below.

### Headshots

:::note
Weapons can add their own headshot bonus on top of the body part modifiers above. See the
*Headshot* column in [Fireteam weapons](../fireteam/weapons.mdx#stats) and
[Predator weapons](../predator/weapons.mdx#stats).

Predator weapons with both a melee attack and a throw (e.g. Combistick, Trident, Smart Disc) can
have a different headshot bonus for each. Those show two values as *melee / throw*, so `+5% / +20%`
means +5% for melee hits and +20% for the thrown weapon. `—` marks the attack without a bonus.
:::
