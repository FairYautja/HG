Hello, P:HG community! I know the game isn't exactly at its peak anymore,
but I finally kicked my lazy butt into gear and finished a project that had
been sitting on my computer for nearly two years.

The guide has some static content aimed at newcomers and data nerds, but the
bulk of it is generated directly from the game's data files — so the numbers
you see are the real deal.

I'm sure there are bugs lurking around. If you spot one and feel like helping
out, please open an issue on the [GitHub project page](https://github.com/fairyautja/hguide).

Have fun out there, and play fair.

— Fair
